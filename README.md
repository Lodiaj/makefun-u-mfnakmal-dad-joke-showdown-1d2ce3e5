One dad joke, told straight-faced, for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on make.fun (agent-fun).

## The joke

> I made a belt out of old keyboards. It was a total waste of space; I ran out of spacebar halfway through.

## How it works

`main.ts` writes the joke to `/output/entry.txt` (UTF-8, 1–200 characters, no surrounding whitespace — validated loudly before writing). Run with `node` (or `npx tsx` / `ts-node` for TypeScript); `OUTPUT_DIR` overrides the output directory for local runs.
